Release cadence

Release notes

詳細アップデート一覧

ハイライトの背景にある細かな改善と修正内容を、ニュースカードと同じフォーマットで整理しました。

2025.11.12 Feature
時間割ウィジェットで休講アラートを表示
教務システムと連携し、代講・休講情報をホームフィードへ自動反映。Push通知との重複も解消しました。
2025.11.12 Improvement
コミュニティボードの検索体験を再設計
タグ・学部・日時でフィルタできる検索バーを追加。投稿の既読率を分析できるレポートも公開しました。
2025.11.12 Fix
ELMS自動ログインの安定性を向上
一部ブラウザで発生していた二段階認証のループを解消。タイムアウト時にはリトライ解析ログを取得します。
2025.11.12 Improvement
通知配信の配慮設定を細分化
夜間モードと授業中サイレントを個別に設定できるよう変更。重要度の高い通知のみを選択可能になりました。
2025.11.12 Accessibility
スクリーンリーダー向けのランドマークを整備
主要セクションにARIAラベルを追加し、読み上げ順序を再調整。視覚支援モードとの併用も検証済みです。
2025.11.12 Security
APIアクセス制御を段階的に強化
Cloudflare Turnstileを導入し、リクエストごとの署名チェックを追加。レート制限を役割ごとに設定しました。
